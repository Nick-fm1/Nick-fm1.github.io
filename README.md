## 💡 Enfoque y Criterio Técnico

Este portafolio va más allá de un *showcase* visual: está construido bajo principios estrictos de **arquitectura de software limpia, rendimiento sin dependencias y accesibilidad universal (WCAG AA)**.

* **Zero-Dependency Core:** Desarrollado con HTML5 semántico, CSS3 moderno (Custom Properties, Flexbox, CSS Grid) y JavaScript Vanilla. Cero sobrecarga de frameworks o compiladores innecesarios.
* **Integración WebGL / 3D:** Implementación eficiente de componentes `<model-viewer>` de Google con renderizado 3D interactivo, sombras dinámicas y adaptación automática al modo claro/oscuro.
* **Rendimiento y Carga Instantánea:** Animaciones aceleradas por hardware y estructura optimizada para maximizar métricas en Google Lighthouse (Performance, Accessibility, Best Practices, SEO).
* **Diseño Adaptativo e Inclusivo:** Enfoque *Mobile-First*, soporte completo para navegación por teclado, contraste verificado y adaptación a la preferencia de color del sistema operativo.
